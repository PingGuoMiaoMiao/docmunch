# 背景：MoonBit 比赛调研（2026-11）

本文件是 docmunch 项目的立项背景。调研时间 2026-11-07。

## 一句话结论

MoonBit 官网列的 5 个赛事里，**现在唯一还能报名的是「2026 MoonBit 年度黑客松 · 十一月赛」**（第二赛季度 2026-11-01 → 2027-01-31）。奖金结构：月度 150+350 元支持、季度一等奖 12,000、半年度 24,000、年度 36,000（可叠加，合计 72,000 元）、季度奖金池 80,000 元、推荐 50 元/人、MVP 补贴 2k–5k/月。硬门槛是 **MoonBit 为主语言 + 公开仓库 + 可运行 + 测试 + OSI 许可 + AI 可解释**。

- [`topic-shortlist.md`](topic-shortlist.md) — 4 个候选选题 + 生态重叠核对 + 评分矩阵 + 四周节奏模板
- [`../sources/scc-2026-recommended-topics.pdf`](../sources/scc-2026-recommended-topics.pdf) — 官网原始 PDF：2026 SCC 官方推荐项目清单（12 个方向）

## 关键事实速查

- **报名**：飞书表单；必须加入赛事微信群，群昵称改成自己的 GitHub ID，否则影响奖金发放。
- **组队**：≤3 人；2 人队各 1/2，3 人队各 1/3；个人也能参赛。
- **截止日**：官方**未公布**，页面统一写「以官方通知为准」。别信任何"据说"的日期。
- **已有项目**：可以交，但必须有本期实质新增；重复提交/拆分项目/简单改动不计分。
- **AI**：可用，但官方明确「这不是提示词比赛」——你要能解释每个技术取舍。
- **奖金口径疑点**：季度单项奖合计 63,000 元，与官网「奖金池 80,000 元」对不上，建议直接问赛事组。

## 为什么选 docmunch

选题短名单里的首选 `docmunch`（文档 → 带来源定位的 Markdown + RAG 分块）在 MoonBit 生态里对应官方推荐清单第 3 项「通用文件格式转换库」，且底层解析件（`pdflite`/`docx2html`/`mbtexcel`）已由官方提供到可用版本，缺的正是"统一 + 定位 + 分块"这一层——也就是本项目要做的部分。
